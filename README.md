### ☁️ Cloud / Deployment

로컬에서는 정상적으로 동작했던 파일 저장 및 AI Server 호출 방식이  
ECS Fargate 환경에서는 그대로 사용할 수 없었습니다.

이를 해결하기 위해

- 상품 이미지 → Private S3 저장
- DB → S3 Object Key만 저장

- AI Server → CloudMap 기반 Service Discovery
- 민감정보 → SSM Parameter Store
- 인프라 → CloudFormation

구조로 변경했습니다.

이 과정에서 **Docker Image를 만드는 것과 실제 Cloud 환경에서 서비스를 운영하는 것은 다른 문제**라는 점을 배웠습니다.

```text
    ↓
GitHub Actions
    ↓
Build / Test
    ↓
Docker Image
    ↓
Amazon ECR
    ↓
Amazon ECS Fargate
    ↓
RDS / S3 / ALB
```

AWS 환경에서는 `ECR`, `ECS Fargate`, `RDS`, `S3`, `ALB` 등을 사용했으며
